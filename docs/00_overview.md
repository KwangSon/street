# 00. 제품 개요

## 1. 제품 정의

**Street**는 에도 시대풍 길거리 가판대에서 시작하는 2D 모바일 타이쿤이다. 플레이어는 작은 가게에서 직접 초밥을 만들고 서빙하며 엽전을 모은다. 이후 좌석, 조리대, 직원을 해금해 자신이 하던 반복 업무를 자동화한다.

첫날은 준비된 재료로 바로 영업한다. 첫 영업이 끝난 뒤부터는 새벽 시장에서 다음 날 재료를 사고 손질하는 짧은 준비 파트가 추가된다.

### 엘리베이터 피치

> 좁은 가판대에서 혼자 뛰어다니던 장사가, 메뉴와 손님과 직원이 늘며 가게 전체가 자동으로 돌아가는 모습을 만드는 게임.

## 2. 제품 사양

| 항목 | 기준 |
|---|---|
| 장르 | 캐주얼 타이쿤 / 경영 자동화 |
| 플랫폼 | 모바일 |
| MVP 테스트 기준 | Android 스마트폰 |
| 화면 방향 | 세로 9:16 |
| 카메라 | 경계 안에서 드래그로 이동하는 2D 쿼터뷰 |
| 한 세션 | 일반 하루 6~7분 |
| 입력 | 플레이 영역 탭으로 주인공 이동, 드래그로 카메라 이동 |
| 엔진 | Godot 2D |
| 그래픽 제작 | Blender에서 렌더한 투명 PNG 스프라이트 |
| 방향 수 | 4방향 |

Android는 테스트 기준일 뿐 출시 플랫폼 확정이 아니다. 스토어 출시 준비, iOS 대응, 결제와 광고는 이 MVP 범위에 포함하지 않는다.

## 3. 목표 이용자

### 1차 이용자

- 복잡한 경영표보다 화면에서 성장하는 모습을 좋아하는 이용자
- 짧은 시간 직접 움직인 뒤 자동화되는 방치형·타이쿤 장르 이용자
- 귀엽고 따뜻한 음식점 테마를 선호하는 이용자
- 한 번에 5~10분 플레이하는 모바일 이용자

### 이용자에게 요구하지 않는 것

- 일본 역사 지식
- 정교한 요리 조작
- 복잡한 재고 계산
- 빠른 반사 신경
- 전투 숙련

## 4. 제품 기둥

### 4.1 직접 하던 일이 자동화된다

처음에는 주인공이 제작, 서빙, 엽전 회수를 모두 맡는다. 첫 직원이 들어오면 서빙이 자동화되고, 플레이어는 제작과 확장에 집중한다. 자동화 전후가 화면에서 즉시 비교돼야 한다.

### 4.2 성장은 숫자보다 화면에서 먼저 보인다

좌석, 조리대, 천막, 간판, 종이등, 직원과 손님이 늘어난다. 시설 레벨이 올라도 외형이나 연출 변화가 전혀 없다면 성장 보상이 부족한 것으로 판단한다.

### 4.3 오늘의 장사가 내일의 준비로 이어진다

영업으로 번 엽전은 다음 날 재료 구매와 가게 확장에 함께 사용된다. 새벽 준비는 별도 장르가 아니라 다음 영업의 판매 가능 수량을 결정하는 짧은 보조 루프다.

### 4.4 맵을 둘러보며 병목을 이해한다

Day 1의 핵심 동선은 초기 화면 안에서 읽혀야 한다. 확장 시설은 경계 안에서 카메라를 드래그해 확인하며, 손님 줄, 비어 있는 조리대, 쌓인 완성품, 남은 재료, 바닥의 엽전을 통해 막힌 지점을 알아볼 수 있어야 한다. 상세 통계창을 열어야만 문제를 이해할 수 있는 설계는 지양한다.

## 5. 핵심 경험 흐름

```text
손님 주문
→ 플레이어가 초밥 제작
→ 손님에게 서빙
→ 엽전 회수
→ 좌석·조리대·직원 해금
→ 저녁 정산
→ 새벽 재료 구매·손질
→ 더 큰 다음 날 영업
```

## 6. 차별점

Eatventure식 직접 이동과 자동화 성장에 **하루 단위 준비와 영업의 연결**을 더한다.

- 일반 영업 중에는 빠르고 직관적인 타이쿤 감각을 유지한다.
- 영업이 끝나면 다음 날 예상 판매량만큼 재료를 구매한다.
- 산 재료를 배치 작업으로 손질하면 다음 날 판매 가능 수량이 된다.
- 과하게 사면 저녁에 남은 재료가 폐기되고, 적게 사면 조기 품절된다.

재료의 등급, 실시간 신선도, 흥정, 랜덤 시세는 넣지 않는다. MVP에서 필요한 선택은 “내일 몇 인분을 준비할 것인가” 하나다.

## 7. 플레이테스트 성공 기준

초기 프로토타입은 매출이 아니라 이해도와 재미를 검증한다.

| 지표 | 목표 |
|---|---:|
| 시작 후 첫 판매 | 30초 이내 |
| 첫 업그레이드 | 60초 이내 |
| 두 번째 좌석 해금 | 2~3분 |
| 첫 직원 고용 | 4~5분 |
| 첫날 정산 도달 | 약 6분 |
| 둘째 날 영업 시작 | 게임 시작 후 8분 이내 |
| 새벽 준비 소요 | 2분 이내 |
| 도움 없이 핵심 루프를 설명한 테스터 | 5명 중 4명 이상 |
| Day 1 → Day 2 전환 완주 | 5명 중 4명 이상 |

정성 질문은 다음 세 개로 통일한다.

1. 언제 가게가 더 편해졌다고 느꼈는가?
2. 다음에 무엇을 해금하고 싶었는가?
3. 새벽 준비가 영업에 영향을 준다는 점을 이해했는가?

## 8. 명시적 비목표

- 전투, 디펜스, 무기, 적
- 정교한 칼질·리듬·타이밍 요리 미니게임
- 역사적 사건을 재현하는 시뮬레이션
- 다지점 운영, 배달, 예약, 오마카세
- 랜덤 시세, 흥정, 신선도 등급
- 직원 능력치, 희귀도, 장비, 뽑기
- 온라인 기능, 경쟁, 길드
- 광고, 결제, 라이브 운영
- 8방향 또는 풀 3D 캐릭터

## 9. 제품 톤

- 역사 교과서보다 밝은 시대극
- 바쁨은 느껴지지만 실패 압박은 낮음
- 음식은 먹음직스럽고 캐릭터는 읽기 쉬움
- 과장된 코믹 연출은 허용하되 현대 물건은 사용하지 않음

“에도”는 제목이나 이용자 지식에 의존하지 않는다. 배경은 시각적 매력과 가판 초밥이라는 출발점을 제공하는 장치다.

# 11. Stage 02 — 넓은 점포 이전 기반

## 1. 목적

Stage 02는 Stage 01에서 번 돈으로 더 넓은 장소를 사는 첫 장소 이전이다. 이번 범위는 장소 구매, 이전 시 보존·초기화 계약, 넓어진 영업 공간과 기존 핵심 루프의 재시작까지다.

Stage 02 전용 메뉴, 다섯 번째 이후 좌석, 새 직원 역할과 Stage 02 완료 조건은 아직 추가하지 않는다.

## 2. 구매 규칙

- 구매 가격 초기값은 **500문**이다.
- Stage 01의 하루 정산 화면에서만 구매할 수 있다.
- 500문이 부족하면 부족 금액을 표시하고 이전을 실행하지 않는다.
- 구매하지 않고 `새벽 장보기로`를 선택해 Stage 01 영업을 계속할 수 있다.
- 구매가 확정되면 같은 낮 화면을 Stage 02 배치로 즉시 다시 만들고 저장한다.
- Stage 02에 들어간 뒤에는 같은 장소를 다시 구매할 수 없다.

## 3. 이전 데이터 계약

이전할 때 유지하는 값은 메뉴 해금과 메뉴 레벨뿐이다.

| 구분 | Stage 02 시작 상태 |
|---|---|
| 고등어 메뉴 | 해금 및 현재 레벨 유지 |
| 계란 메뉴 | 잠금/해금 및 현재 레벨 유지 |
| 보유금 | 0문으로 초기화 |
| 날짜 | Stage 02 Day 1 |
| 좌석 | 기본 좌석 1개 |
| 직원·주급일 | 전부 초기화 |
| 재고 | 이전 재고는 폐기하고 새 장소 시작 지급량 적용 |
| 누적 판매·매출·폐기 | Stage 02 기준으로 초기화 |
| 손님·주문·접시·결제·예약 | 전부 초기화 |

새 장소 시작 지급량은 Stage 01 첫날과 같은 밥 20인분, 고등어 20인분이다. 계란 메뉴를 유지했더라도 계란 재고는 0으로 시작하며 다음 새벽부터 구매한다. 이는 이전 재고 보존이 아니라 새 장소의 진행 불능을 막는 시작 지급이다.

## 4. 공간 계약

- Stage 01 맵은 1200 × 1920, Stage 02 맵은 **1600 × 2400**이다.
- Stage 02에는 `Stage 2 · 넓은 점포` 표식을 표시한다.
- 생선류·밥·기타요리·조리대 네 주방 카테고리는 유지하되 더 넓게 재배치한다.
- 입구, 대기열, 기본 좌석과 향후 좌석 위치를 새 장소 좌표로 다시 배치한다.
- Stage 01에서 구매한 좌석 노드는 남기지 않는다.
- 카메라·경로 탐색·충돌 경계는 Stage 02 크기를 사용한다.

## 5. 플레이 흐름

```text
Stage 01 정산
→ 500문 장소 구매
→ 메뉴 해금·레벨만 보존
→ Stage 02 Day 1, 0문, 좌석 1, 직원 없음
→ 시작 재고로 즉시 영업
→ 정산·새벽 시장·다음 날 영업 반복
```

Stage 02에서도 주문, 제작, 서빙, 결제, 직원 자동화, 정산과 새벽 준비 규칙은 동일하다.

## 6. 수용 기준

- Stage 01 영업 중이나 새벽에는 장소 구매가 실행되지 않는다.
- Stage 01 정산에서 499문이면 구매가 막히고 1문 부족을 표시한다.
- Stage 01 정산에서 500문 이상이면 정확히 한 번 Stage 02로 이전한다.
- 이전 전의 메뉴 잠금/해금과 레벨은 그대로 유지된다.
- 돈, 좌석, 직원, 재고, 날짜, 누적 기록과 진행 중 작업은 이전되지 않는다.
- Stage 02 시작 시 밥 20·고등어 20·계란 0, 좌석 1로 영업 가능하다.
- Stage 02 맵과 카메라 경계는 1600 × 2400이며 Stage 01 좌석 배치가 남지 않는다.
- 이전 직후 저장·재실행해도 Stage 02 시작 상태가 복구된다.
- Stage 02 정산에는 장소 구매 버튼이 다시 나타나지 않는다.

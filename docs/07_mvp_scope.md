# 07. MVP 범위와 완료 정의

## 1. MVP 정의

이 문서에서 MVP는 스토어 출시판이 아니라 **Stage 01을 처음부터 끝까지 플레이하고 핵심 재미를 검증할 수 있는 내부용 버티컬 슬라이스**다.

완료 상태는 다음 한 문장으로 정의한다.

> 새 게임을 시작해 첫날 영업, 정산, 새벽 구매와 손질, 둘째 날 영업, 직원 자동화, 계란 메뉴 해금, Stage 01 완료까지 저장 오류나 진행 불능 없이 플레이할 수 있다.

## 2. 포함 범위

### 플레이

- 세로형 2D 쿼터뷰 맵과 경계가 있는 수동 카메라 이동
- 주인공 4방향 이동
- 접근 시 자동 제작·서빙·회수·손질
- 손님 입장, 착석, 주문, 식사, 결제, 퇴장
- 대기열 최대 3명
- 재료 부족과 품절
- 고등어·계란 초밥
- 엽전 획득과 사용

### 성장

- 고등어 조리대 Lv.1~5
- 계란 조리대 Lv.1~3
- 좌석 1~4
- 점원 1명 고용과 속도 강화
- 가판 외형 3단계
- Stage 01 목표와 완료 연출

### 하루 구조

- Day 1은 준비 재료로 즉시 영업
- 영업 타이머와 저녁 마감
- 정산
- 5인분 단위 재료 구매
- 쌀, 고등어, 계란 배치 손질
- 남은 재료 폐기
- 다음 날 전환

### 제품 품질

- 단계 전환 자동 저장
- 일시정지와 재개
- 기본 설정: 배경 음악·효과음 음량
- Android 테스트 빌드
- 임시 분석 로그 또는 수동 테스트 기록

## 4. 기능 수용 기준

### 이동과 상호작용

- 고정 UI 밖을 탭하면 해당 월드 위치로 이동하고 시설이 가로막으면 자동으로 우회한다.
- 이동 방향에 맞는 스프라이트가 100ms 안에 전환된다.
- 고정 UI 밖을 드래그하면 카메라가 맵 경계 안에서 움직이고 회전하거나 확대·축소하지 않는다.
- 8픽셀 미만 움직임은 이동 탭, 8픽셀 이상 움직임은 카메라 드래그로 판정한다.
- 이동 중 카메라를 드래그해도 기존 목적지가 유지된다.
- 단계가 시작되면 카메라가 해당 플레이 영역의 기본 위치로 초기화된다.
- 시설에 접근하면 별도 제작 버튼 없이 작업한다.
- 같은 범위에 대상이 겹쳐도 잘못된 물건을 반복해서 집지 않는다.
- 캐릭터가 시설, 좌석, 화면 밖에 영구적으로 끼지 않는다.

### 손님

- 빈 좌석이 있으면 손님이 도달해 주문한다.
- 잠긴 메뉴를 주문하지 않는다.
- 주문과 다른 음식을 받지 않는다.
- 식사 후 정확한 판매가만큼 엽전을 생성한다.
- 이탈하거나 퇴장한 손님이 대기열과 좌석을 정상 반납한다.

### 성장

- 보유금보다 비싼 항목은 구매되지 않는다.
- 운영자금 10문 보호가 영업 중 적용된다.
- 해금과 강화가 저장 후에도 유지된다.
- 점원은 고용 직후 자동 서빙을 시작한다.
- 가판 외형 변화가 조건과 정확히 일치한다.

### 하루 구조

- Day 1에는 구매·손질을 요구하지 않는다.
- 구매량과 준비량이 판매 가능 재고에 정확히 반영된다.
- 정산의 판매량, 매출, 이탈, 폐기량이 실제 기록과 일치한다.
- 재료가 없어도 조기 마감으로 진행할 수 있다.
- 구매 완료 전에는 전액 되돌리기가 가능하다.

### 저장

- 영업 시작, 정산 완료, 구매 완료, 준비 완료, Stage 완료 시 자동 저장한다.
- 시장에서 확정하지 않은 구매는 재실행 시 복구하지 않는다.
- 앱을 강제 종료한 뒤 마지막 완료 단계에서 재개한다.
- 잘못되거나 오래된 저장 데이터는 새 게임 선택지를 제공하고 무한 로딩하지 않는다.

## 5. 사용자 경험 수용 기준

- 첫 판매 중앙값 30초 이내
- 첫 업그레이드 중앙값 60초 이내
- 첫 직원 고용 중앙값 5분 이내
- 첫 정산 중앙값 6분 이내
- Day 2 시작 중앙값 8분 이내
- 새벽 파트 중앙값 90초 이내, 최대 2분
- 테스트 참가자 5명 중 4명 이상이 “직원이 내가 하던 서빙을 대신한다”고 설명
- 테스트 참가자 5명 중 4명 이상이 “오늘 산 재료가 내일 판매량을 정한다”고 설명

## 6. 기술 품질 기준

- 기준 기기: Android 10 이상, 메모리 4GB급 스마트폰
- 목표: 일반 플레이 60fps
- 허용 최저: 손님과 직원이 최대치일 때 30fps 아래로 2초 이상 내려가지 않음
- 첫 화면 진입: 5초 이내
- 30분 연속 플레이 중 크래시 0회
- Day 1 → Day 3 반복 10회에서 진행 불능 0회
- 저장·재개 테스트 20회에서 데이터 유실 0회
- 터치 영역은 시각 요소보다 넓고 최소 약 44pt 확보

기준 기기는 개발 초기에 실제 모델 하나를 지정해 문서에 추가한다.

## 7. 완료 판정 체크리스트

### 제품

- [ ] 제품 기둥 3개 이상이 플레이테스트에서 관찰됨
- [ ] 핵심 시점 목표 충족
- [ ] 새벽 준비가 영업보다 길거나 복잡하지 않음
- [ ] Stage 01 완료 시간이 20~30분

### 범위

- [ ] 포함 기능 전부 구현
- [ ] 제외 기능이 빌드에 섞이지 않음
- [ ] 콘텐츠 목록의 최종 에셋 연결
- [ ] 임시 에셋 잔존 여부 기록

### 품질

- [ ] 치명적·진행 불능 버그 0개
- [ ] 높은 우선순위 버그 0개
- [ ] 보통 우선순위 버그는 우회 방법과 후속 일정 기록
- [ ] 성능·저장 기준 통과
- [ ] PM 최종 플레이 3회 연속 완주

## 8. Go / No-Go 기준

다음 조건을 모두 만족하면 후속 장소 제작으로 진행한다.

- 5명 중 4명 이상이 첫날을 이탈 없이 완료
- 5명 중 3명 이상이 “다음 시설을 열고 싶다”고 자발적으로 표현
- 점원 고용 전후의 차이를 5명 중 4명 이상이 체감
- 새벽 준비를 지루하다고 답한 이용자가 5명 중 2명 이하
- 진행 불능 버그 0개

조건을 만족하지 못하면 Stage 02를 만들지 않고 핵심 루프를 수정한다.

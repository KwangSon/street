# 06. 아트 방향

## 1. 아트 목표

> 밝고 귀여운 에도 시대풍 가판 초밥집을, 한눈에 읽히는 저디테일 2D 쿼터뷰로 표현한다.

정확한 역사 재현보다 모바일 화면의 가독성과 성장 연출을 우선한다. 캐릭터와 시설은 Blender의 단순한 3D 모델을 고정 카메라로 렌더해 2D PNG로 사용한다.

## 2. 핵심 키워드

- 밝은 시대극
- 작은 디오라마
- 둥근 저디테일 형태
- 따뜻한 나무색
- 선명한 음식 색
- 큰 실루엣
- 한 화면에서 읽히는 동선

## 3. 피해야 할 방향

- 사실적인 인체 비례와 재질
- 어둡고 탁한 역사 다큐멘터리 톤
- 복잡한 문양과 작은 소품
- 음식보다 눈에 띄는 배경 장식
- 현대식 냉장고, 금전 등록기, 플라스틱 식기
- 다른 게임의 캐릭터, UI, 아이콘, 색 배치 또는 고유 오브젝트 복제

Eatventure에서는 고정 화면, 직접 이동, 접근 자동 작업이라는 **상호작용 문법**만 참고한다. 화면 구성과 아트 표현은 Street의 강가 가판대와 하루 루프에 맞게 새로 만든다.

## 4. 화면 기준

| 항목 | 기준 |
|---|---|
| 기준 화면 | 1080 × 1920, 세로 9:16 |
| 개발 기준 내부 해상도 | 540 × 960 |
| 카메라 | 고정 |
| 플레이 영역 | 화면 중앙 약 70% |
| 상단 안전 영역 | HUD 및 기기 노치 고려 |
| 하단 안전 영역 | 조이스틱·단계 전환 버튼 |

고정 카메라 안에서 시작 상태와 완성 상태가 모두 보여야 한다. 확장을 위해 카메라를 줌아웃하지 않는다.

## 5. Blender 렌더 기준

모든 에셋은 동일한 씬 템플릿을 사용한다.

### 카메라

- 직교 카메라
- 방위각 45도
- 고도 약 35도
- 동일한 초점 거리와 오브젝트 스케일
- 캐릭터 네 방향은 게임 월드의 상·하·좌·우를 기준으로 회전

정확한 카메라 수치는 첫 캐릭터와 첫 조리대 테스트 후 고정한다. 고정 이후 개별 에셋마다 각도를 바꾸지 않는다.

### 조명

- 화면 좌상단의 부드러운 주광 1개
- 약한 보조광
- 과도한 반사와 금속광 금지
- 접지 그림자는 PNG에 굽지 않고 Godot의 타원형 그림자로 통일

### 렌더

- 투명 배경 PNG
- 실제 사용 크기의 2배로 렌더한 뒤 축소
- 색상 관리는 동일한 뷰 변환 사용
- 발 위치와 오브젝트 바닥 중심을 기준점으로 통일
- 프레임마다 캔버스 크기가 바뀌지 않음

## 6. 형태 언어

### 캐릭터

- 머리가 몸 전체의 약 35~40%
- 짧은 팔과 다리
- 손과 발은 단순한 덩어리
- 얼굴은 눈, 눈썹, 입 정도만 사용
- 역할은 실루엣과 색으로 구분

역할별 표식:

- 주인: 흰 머리띠, 짙은 앞치마
- 점원: 밝은 앞치마, 접시를 드는 자세
- 손님: 기모노 색과 머리 형태로 변형
- 상인: 넓은 소매, 상인 두건, 재료 광주리

### 시설

- 상호작용 시설은 장식보다 크고 단순하게 표현
- 작업 면은 밝게, 밑면은 어둡게 해 입체감 확보
- 상태 변화는 크기, 진열 수량, 장식 추가로 표현
- 클릭/접근 범위와 시각적 바닥 면적이 크게 어긋나지 않음

### 음식

- 실제보다 130~150% 크게 표현
- 고등어는 푸른 회색, 계란은 선명한 노란색
- 접시 테두리 색을 달리해 축소 화면에서도 구분

## 7. 색 기준

### 기본 팔레트 역할

- 나무와 천막: 따뜻한 갈색·베이지
- 강가와 하늘 반사: 낮은 채도의 청록
- 상호작용 가능: 밝은 금색
- 업그레이드 가능: 따뜻한 노랑
- 재료 부족: 붉은 주황
- 완료: 연두 또는 청록
- 엽전: 탁하지 않은 황동색

화면의 포인트 색은 음식, 주문, 구매 패드에 우선 배정한다. 배경 장식에 같은 채도의 포인트 색을 반복하지 않는다.

## 8. 애니메이션 기준

- 기본 재생 속도: 초당 6프레임
- 걷기 한 주기: 약 0.8초
- 작업 한 주기: 0.6~1.0초
- 과장된 상하 움직임으로 작은 화면에서도 상태가 보이게 함
- 방향 전환 시 발 기준점이 튀지 않음
- 운반물은 캐릭터 프레임에 굽지 않고 부착물로 처리

앉기와 먹기는 좌석이 향하는 방향만 제작한다. 모든 행동을 4방향으로 만들지 않아도 되지만, 월드에서 이동하는 캐릭터의 대기와 걷기는 반드시 4방향이다.

## 9. 정렬과 가독성

- 캐릭터와 시설의 겹침은 발 위치 Y값을 기준으로 정렬
- 지붕·천막이 캐릭터를 장시간 가리지 않음
- 주문 아이콘은 캐릭터 머리 위 일정 높이에 표시
- 진행 게이지는 같은 위치와 크기 사용
- 조이스틱 손가락 영역이 시설 해금 패드와 겹치지 않음

## 10. 파일 규칙

```text
art/
├── characters/
│   ├── owner/
│   ├── server/
│   ├── customers/
│   └── merchant/
├── food/
├── stations/
├── environment/
├── ui/
└── fx/
```

권장 파일명:

```text
ch_owner_walk_down_00.png
ch_owner_work_left_03.png
st_mackerel_counter_lv02.png
fd_mackerel_sushi.png
ui_order_egg.png
```

방향 표기는 `up`, `down`, `left`, `right`로 통일한다.

## 11. 아트 검수 기준

- 540 × 960 화면에서 주인, 점원, 손님을 즉시 구분할 수 있다.
- 네 방향 프레임의 크기, 중심, 발 위치 차이가 2픽셀 이내다.
- 고등어와 계란 주문 아이콘을 색각에만 의존하지 않고 형태로도 구분한다.
- 시설의 잠김, 구매 가능, 완료 상태가 색 외에도 실루엣 또는 표시로 구분된다.
- 동일한 카메라와 조명을 사용한 것처럼 모든 에셋이 한 화면에 자연스럽게 놓인다.
- 10분 플레이에서 중요한 주문과 재료 수량이 장식에 가려지지 않는다.

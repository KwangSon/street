# 08. 제작 일정

## 1. 일정 가정

- 1인 개발 기준
- 하루 5~6시간의 집중 작업
- Godot 2D 기본 사용 가능
- Blender는 단순 모델, 고정 카메라 렌더, 애니메이션 출력 범위
- 주말과 외부 마켓 에셋 검수 시간은 일정에 포함하지 않음
- 총 일정: **10근무일 프로토타입 + 승인 후 4주 버티컬 슬라이스**

일정은 기능 완성 순서이며 달력 날짜가 아니다. 선행 마일스톤이 통과되지 않으면 후속 콘텐츠 제작을 시작하지 않는다.

이 문서는 마일스톤의 기간과 승인 조건을 관리한다. 실제 코드 구현 순서, 근무일별 작업, 선행 의존성은 [`10_implementation_order.md`](10_implementation_order.md)를 따른다. 두 문서가 충돌하면 범위와 기간은 이 문서, 같은 기간 안의 실행 순서는 10번 문서를 우선한다.

## 2. Milestone P0 — 10일 재미 검증 프로토타입

그래픽은 임시 에셋을 허용한다. 목표는 Day 1에서 Day 2로 이어지는 루프가 실제로 재미있는지 검증하는 것이다.

| 일차 | 목표 | 산출물 | 완료 조건 |
|---:|---|---|---|
| 1 | 실행 기반 | 메인 진입점, `GameManager` 초기 상태, GUT 테스트 발견 | 프로젝트 시작, 새 게임 초기값, 단계 전환 테스트 정상 |
| 2 | 맵과 입력 | 코드 기반 회색 맵, 탭 목적지 이동, 드래그 카메라 | 이동, 경로 우회, 충돌, 카메라 경계 정상 |
| 3 | 시설 접근 작업 | 고등어 제작, 완성 접시 적재·회수 | 버튼 없이 제작·회수 20회 성공 |
| 4 | 손님 상태 흐름 | 입장→착석→주문→퇴장 | 손님 10명 연속 진행 불능 없음 |
| 5 | 판매 전체 연결 | 제작→서빙→엽전 | 첫 판매 30초 이내 |
| 6 | 성장 | 조리대 강화, 좌석 2 | 구매·해금·수치 반영 정상 |
| 7 | 자동화 | 점원 고용과 자동 서빙 | 고용 후 10초 안에 서빙 시작 |
| 8 | 하루 종료 | 타이머, 마지막 주문, 정산 | 판매·매출·폐기 수치 일치 |
| 9 | 새벽 파트 | 구매, 고등어·쌀 손질 | 구매량이 Day 2 재고로 연결 |
| 10 | 통합과 빌드 | Android 테스트 빌드 | Day 1→Day 2 3회 연속 완주 |

### P0 통과 기준

- 첫 판매 30초 이내
- 첫 업그레이드 60초 이내
- 첫 직원 5분 이내
- 첫 정산 약 6분
- Day 2 시작 8분 이내
- 3명 이상의 짧은 플레이테스트 완료
- 진행 불능과 크래시 0개

P0가 통과하지 못하면 최종 아트를 만들기 전에 2~3일의 수정 스프린트를 추가한다.

## 3. Milestone M1 — 버티컬 슬라이스 1주차

### 목표

핵심 영업을 안정화하고 저장 가능한 제품 구조로 만든다.

### 작업

- 이동 감각과 충돌 수정
- 상호작용 우선순위 확정
- 손님 대기열과 이탈
- 고등어 조리대 Lv.1~5
- 좌석 1~4
- 점원 속도 강화
- Day 1 행동형 튜토리얼
- 일시정지와 재개
- 단계 전환 자동 저장
- 임시 분석 로그

### 완료 조건

- Day 1 10회 반복에서 진행 불능 0회
- 첫날 목표 시점이 허용 범위 안에 들어옴
- 저장 후 영업 시작 상태 복원

## 4. Milestone M2 — 버티컬 슬라이스 2주차

### 목표

구매·손질·정산을 제품 수준으로 연결한다.

### 작업

- 시장 구매와 되돌리기
- 쌀·고등어 배치 손질
- 계란 구매·손질
- 계란 조리대 Lv.1~3
- 품절과 폐기
- 정산 상세
- 운영자금 10문 보호
- Stage 01 목표와 완료 조건

### 완료 조건

- Day 1→Day 3 5회 연속 완주
- 구매·준비·판매·폐기 수량 오차 0
- 새벽 파트 평균 90초 이하
- Stage 01 완료 20~30분

## 5. Milestone M3 — 버티컬 슬라이스 3주차

### 목표

임시 표현을 최종 아트와 사운드로 교체한다.

### 작업

- 주인, 점원, 손님 2종, 상인 프리렌더
- 4방향 이동 애니메이션
- 가판 외형 3단계
- 영업·준비 시설
- 음식과 재료
- HUD, 주문, 패드, 정산 UI
- 기본 효과와 사운드
- 영업·새벽 배경 음악
- 배경 음악·효과음 음량 설정

### 완료 조건

- `05_content_list.md`의 MVP 필수 항목 100% 연결
- 네 방향 발 위치와 스케일 검수 통과
- 720 × 1280 화면에서 주문과 시설 구분 가능
- 임시 에셋 잔존 목록 작성

## 6. Milestone M4 — 버티컬 슬라이스 4주차

### 목표

밸런스, 성능, 저장, 이용자 이해도를 검증해 완료 판정을 내린다.

### 작업

- 5명 이상 플레이테스트
- 경제와 손님 간격 조정
- 튜토리얼 문구 축소
- 터치 영역과 모바일 UI 수정
- 성능과 메모리 점검
- 저장·복구 반복 테스트
- 효과와 사운드 믹스
- 버그 분류와 수정
- 최종 Android 빌드와 PM 회귀 테스트

### 완료 조건

- `07_mvp_scope.md`의 완료 체크리스트 통과
- 진행 불능·크래시 0개
- PM 3회 연속 Stage 01 완주
- Go / No-Go 결과 기록

## 8. 일정 보호 규칙

- P0 동안 최종 아트를 만들지 않는다.
- 자동 조리 장인, Stage 02, 특수 손님은 백로그에도 구현 작업으로 넣지 않는다.
- 하루 파트가 2분을 넘으면 콘텐츠를 추가하지 않고 동선과 작업 수를 줄인다.
- 아트 지연 시 캐릭터 변형 수를 줄이고 핵심 역할 4종은 유지한다.
- 2일 이상 지연되는 기능은 범위 축소안과 일정 연장안을 함께 제시한다.
- 버그 수정 주간에 신규 기능을 추가하지 않는다.

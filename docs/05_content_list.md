# 05. 콘텐츠 목록

## 1. 관리 원칙

이 목록은 Stage 01 버티컬 슬라이스에 필요한 콘텐츠 상한이다. 목록에 없는 콘텐츠는 자동으로 후속 범위가 된다.

- **P0**: 10일 프로토타입에 필요한 임시 콘텐츠
- **MVP**: 4주 버티컬 슬라이스 종료 시 필요한 최종 콘텐츠
- 색상 변형은 새 모델이나 새 동작으로 계산하지 않는다.
- 새 캐릭터 또는 새 메뉴를 추가하려면 같은 규모의 기존 항목을 제거하거나 일정을 다시 산정한다.

## 10. 콘텐츠 완료 조건

- 모든 항목에 ID, 최종 파일, 게임 내 사용 위치가 연결돼 있다.
- 캐릭터 네 방향의 크기와 발 위치가 일치한다.
- 고등어와 계란 주문 아이콘을 1초 안에 구분할 수 있다.
- 시작·성장·완성 가판 외형의 차이를 축소 화면에서도 구분할 수 있다.
- 임시 에셋이 최종 빌드에 남아 있으면 목록에 이유와 교체 일정을 기록한다.
- 목록 밖의 캐릭터, 메뉴, 시설, 효과가 MVP 빌드에 추가되지 않는다.

# 03. Stage 01 — 강가 초밥 가판대

## 1. 스테이지 역할

첫 스테이지는 게임의 모든 확장 기능을 보여주는 장소가 아니다. 다음 세 가지를 증명하는 버티컬 슬라이스다.

1. 직접 움직여 판매하는 기본 루프가 즉시 이해된다.
2. 주방장과 접객 고용이 분명한 자동화 보상으로 느껴진다.
3. 저녁 정산과 새벽 준비가 다음 날 영업에 연결된다.

## 2. 공간 콘셉트

강가 흙길 옆의 작은 가판대다. 낡은 천막, 나무 조리대, 밥통, 생선 상자, 낮은 의자에서 시작한다. 성장하면 천막이 넓어지고 간판과 종이등이 생기며 좌석과 직원이 늘어난다.

### 권장 맵 배치

```text
┌──────────────────────────────┐
│ 날짜/시간       엽전      목표 │
│                              │
│ [생선류] [밥] [조리대]         │
│                    [기타요리]  │
│            주인 이동 공간     │
│                              │
│ 입구/대기열   좌석1  좌석2    │
│              좌석3  좌석4    │
│                              │
│ 직원 UI              해금 UI   │
└──────────────────────────────┘
```

위 배치는 전체 맵의 관계를 나타낸다. 생선류, 밥, 기타요리, 조리대 네 주방 스테이션은 메뉴 해금과 무관하게 고정되며 Day 1부터 존재한다. 이후 메뉴가 늘어도 이 네 스테이션의 수와 역할은 바뀌지 않는다. 직원 고용은 화면 왼쪽 아래, 좌석·메뉴 해금과 강화는 오른쪽 아래 고정 버튼에서 연다. HUD와 두 성장 UI는 카메라와 함께 움직이지 않는다.

## 3. 콘텐츠 구성

| 분류 | Stage 01 범위 |
|---|---|
| 메뉴 | 고등어 초밥, 계란 초밥 |
| 플레이어 | 가판 주인 1명 |
| 직원 | 주방장 1명, 접객 1명 |
| 손님 | 기본 체형 2종, 색상 변형 |
| 상인 | 새벽 재료 상인 1명 |
| 좌석 | 최대 4개 |
| 주방 | 생선류·밥·기타요리·조리대 각 1개 |
| 준비 시설 | 세척대, 손질대, 화로, 얼음 상자, 밥 준비대 |
| 가판 외형 | 시작, 성장, 완성의 3단계 |

## 4. 시작 상태

- Day 1 아침
- 보유 엽전 0문
- 손질 고등어 20인분
- 밥 20인분
- 고등어 메뉴 Lv.1
- 좌석 1개
- 주방장·접객 없음
- 계란 메뉴 잠김

## 5. Day 1 진행 비트

| 목표 시점 | 이용자 경험 | 시스템 결과 |
|---|---|---|
| 0:00~0:30 | 이동, 제작, 첫 서빙 | 첫 6문 획득 |
| 0:30~1:00 | 같은 루프 1~2회 반복 | 고등어 메뉴 Lv.2 가능 |
| 1:00~2:30 | 손님 대기가 보이기 시작 | 좌석 2 해금 |
| 2:30~4:30 | 제작과 서빙이 동시에 밀림 | 접객 고용 가능 |
| 4:30~5:30 | 접객이 주문·서빙·계산을 대신함 | 첫 자동화 체감 |
| 약 5:30 | 마지막 주문 | 첫 정산 진입 |

튜토리얼 문구는 한 번에 하나만 표시하며, 이동을 막는 전체 화면 팝업은 첫 30초에 사용하지 않는다.

## 6. 첫날 필수 튜토리얼 행동

1. 손님에게 접근해 고등어 주문 수령
2. 생선류와 밥 스테이션을 순서대로 방문
3. 공용 조리대에서 1접시 제작
4. 주문 손님에게 접근해 서빙
5. 생성된 엽전 회수
6. 고등어 메뉴 Lv.2 강화
7. 좌석 2 해금
8. 왼쪽 아래 직원 UI에서 접객 고용
9. 저녁 정산 확인

각 행동은 실제 플레이 목표와 일치해야 한다. 설명만 보고 닫는 튜토리얼은 만들지 않는다.

## 7. Day 2 이후 진행

### Day 2 새벽

- 어제 판매·폐기량 확인
- 쌀과 고등어 구매
- 고등어와 쌀 배치 손질
- 준비 완료 후 아침 영업

### Day 2 영업

- 준비량에 따라 품절 또는 폐기를 경험
- 세 번째 좌석과 계란 메뉴 중 하나를 먼저 선택
- 계란 메뉴 해금 시 다음 새벽부터 계란 구매·준비 가능

### Day 3 이후

- 두 메뉴의 수요를 처리
- 좌석 4개까지 해금
- 고등어와 계란 메뉴 강화
- 주방장 고용으로 메뉴 동선 자동 조리
- 스테이지 완성 조건 달성

## 8. 메뉴 역할

### 고등어 초밥

- 시작 메뉴
- 빠르고 값이 낮음
- 기본 생산과 재고 학습용
- 고등어 메뉴 최대 Lv.5
- 낮 동선: `생선류 → 밥 → 조리대`

### 계란 초밥

- 첫 추가 메뉴
- 제작이 조금 느리고 판매가가 높음
- 계란용 새벽 준비 단계를 추가
- 계란 메뉴 최대 Lv.3
- 낮 동선: `기타요리 → 밥 → 조리대`

손님 취향과 선호 메뉴 확률은 메뉴 해금 이후 단순 비율로만 처리한다. 손님 유형별 선호와 만족도는 후속 범위다.

## 9. 가판 외형 성장

외형은 별도 구매가 아니라 진행 마일스톤에 따라 바뀐다.

| 상태 | 조건 | 변화 |
|---|---|---|
| 시작 | 새 게임 | 낡은 천막, 좌석 1, 작은 간판 |
| 성장 | 직원 1명 고용 + 좌석 2 | 넓어진 천막, 식기 더미, 종이등 1 |
| 완성 | Stage 01 완료 | 큰 간판, 종이등 2, 정돈된 조리대, 장식 깃발 |

## 10. 스테이지 완료와 장소 구매

Stage 01의 완료는 별도 목표 묶음이 아니라 **정산 시 새 장소 구매**로 확정한다.

- 새 장소 비용 초기값: 500문
- 구매 가능 시점: Stage 01의 하루 정산
- 구매하지 않으면 새벽 장보기로 넘어가 같은 장소를 계속 운영한다.
- 구매하면 Stage 02의 더 넓은 장소를 열고 Stage 01로 돌아오지 않는다.

고등어·계란 메뉴의 해금과 레벨만 Stage 02로 이어진다. 돈, 좌석, 직원·주급, 재고, 날짜, Stage 누적 기록과 진행 중 작업은 초기화한다.

## 11. 완료 연출

- 정산 화면에 `새 장소로 이전 · 500문` 버튼을 보여준다.
- 부족하면 정확한 부족 금액을 표시한다.
- 구매 버튼에는 `메뉴·레벨만 유지`를 함께 표시한다.
- 구매 후 Stage 02 Day 1 화면을 새 배치로 다시 만든다.

## 12. 스테이지 수용 기준

- Day 1 핵심 시설은 초기 화면에 보이고, 확장 시설은 경계 안의 카메라 이동으로 모두 확인할 수 있다.
- 카메라는 단계 시작 시 관련 플레이 영역으로 초기화되고 맵 밖으로 이동하지 않는다.
- 첫 판매, 첫 업그레이드, 첫 좌석, 첫 직원의 목표 시점을 충족한다.
- Day 1에 시장이나 손질을 요구하지 않는다.
- Day 2에는 구매한 수량이 판매 가능량에 정확히 반영된다.
- 접객이 손님의 주문과 일치하는 메뉴만 전달한다.
- 주방장은 메뉴별 고정 경로를 지키고 조리대에서만 음식을 완성한다.
- 계란 메뉴가 잠겨 있을 때 계란 주문이 발생하지 않는다.
- 장소 구매 비용과 구매 가능 단계가 UI와 내부 판정에서 일치한다.
- 장소 구매 뒤 메뉴 해금·레벨만 유지되고 Stage 02 시작 상태가 저장된다.

# 03. Stage 01 — 강가 초밥 가판대

## 1. 스테이지 역할

첫 스테이지는 게임의 모든 확장 기능을 보여주는 장소가 아니다. 다음 세 가지를 증명하는 버티컬 슬라이스다.

1. 직접 움직여 판매하는 기본 루프가 즉시 이해된다.
2. 점원 고용이 분명한 자동화 보상으로 느껴진다.
3. 저녁 정산과 새벽 준비가 다음 날 영업에 연결된다.

## 2. 공간 콘셉트

강가 흙길 옆의 작은 가판대다. 낡은 천막, 나무 조리대, 밥통, 생선 상자, 낮은 의자에서 시작한다. 성장하면 천막이 넓어지고 간판과 종이등이 생기며 좌석과 직원이 늘어난다.

### 권장 맵 배치

```text
┌──────────────────────────────┐
│ 날짜/시간       엽전      목표 │
│                              │
│ [재료] [밥통] [고등어 조리대] │
│                [계란 조리대]  │
│            주인 이동 공간     │
│                              │
│ 입구/대기열   좌석1  좌석2    │
│              좌석3  좌석4    │
│                              │
│     직원 패드 / 해금 패드      │
└──────────────────────────────┘
```

위 배치는 전체 맵의 관계를 나타낸다. Day 1에 사용하는 재료, 밥통, 고등어 조리대, 좌석 1, 입구는 단계 시작 시 초기 화면에 보여야 한다. 이후 좌석과 계란 조리대는 경계 안에서 카메라를 드래그해 확인할 수 있다. HUD는 카메라와 함께 움직이지 않으며 장식이 이동 목적지, 조작 패드, 주문 아이콘, 재료 수량을 가리지 않는다.

## 3. 콘텐츠 구성

| 분류 | Stage 01 범위 |
|---|---|
| 메뉴 | 고등어 초밥, 계란 초밥 |
| 플레이어 | 가판 주인 1명 |
| 직원 | 점원 1명 |
| 손님 | 기본 체형 2종, 색상 변형 |
| 상인 | 새벽 재료 상인 1명 |
| 좌석 | 최대 4개 |
| 조리대 | 고등어 1개, 계란 1개 |
| 준비 시설 | 세척대, 손질대, 화로, 얼음 상자, 밥 준비대 |
| 가판 외형 | 시작, 성장, 완성의 3단계 |

## 4. 시작 상태

- Day 1 아침
- 보유 엽전 0문
- 손질 고등어 20인분
- 밥 20인분
- 고등어 조리대 Lv.1
- 좌석 1개
- 점원 없음
- 계란 조리대 잠김

## 5. Day 1 진행 비트

| 목표 시점 | 이용자 경험 | 시스템 결과 |
|---|---|---|
| 0:00~0:30 | 이동, 제작, 첫 서빙 | 첫 6문 획득 |
| 0:30~1:00 | 같은 루프 1~2회 반복 | 고등어 조리대 Lv.2 가능 |
| 1:00~2:30 | 손님 대기가 보이기 시작 | 좌석 2 해금 |
| 2:30~4:30 | 제작과 서빙이 동시에 밀림 | 점원 고용 가능 |
| 4:30~5:30 | 점원이 서빙을 대신함 | 자동화 체감, 가판 성장 외형 |
| 약 5:30 | 마지막 주문 | 첫 정산 진입 |

튜토리얼 문구는 한 번에 하나만 표시하며, 이동을 막는 전체 화면 팝업은 첫 30초에 사용하지 않는다.

## 6. 첫날 필수 튜토리얼 행동

1. 손님에게 접근해 고등어 주문 수령
2. 고등어 상자와 밥통을 순서대로 방문
3. 고등어 조리대에서 1접시 제작
4. 주문 손님에게 접근해 서빙
5. 생성된 엽전 회수
6. 고등어 조리대 Lv.2 강화
7. 좌석 2 해금
8. 점원 고용
9. 저녁 정산 확인

각 행동은 실제 플레이 목표와 일치해야 한다. 설명만 보고 닫는 튜토리얼은 만들지 않는다.

## 7. Day 2 이후 진행

### Day 2 새벽

- 어제 판매·폐기량 확인
- 쌀과 고등어 구매
- 고등어와 쌀 배치 손질
- 준비 완료 후 아침 영업

### Day 2 영업

- 준비량에 따라 품절 또는 폐기를 경험
- 세 번째 좌석과 계란 조리대 중 하나를 먼저 선택
- 계란 조리대 해금 시 다음 새벽부터 계란 구매·준비 가능

### Day 3 이후

- 두 메뉴의 수요를 처리
- 좌석 4개까지 해금
- 고등어와 계란 조리대 강화
- 스테이지 완성 조건 달성

## 8. 메뉴 역할

### 고등어 초밥

- 시작 메뉴
- 빠르고 값이 낮음
- 기본 생산과 재고 학습용
- 고등어 조리대 최대 Lv.5

### 계란 초밥

- 첫 추가 메뉴
- 제작이 조금 느리고 판매가가 높음
- 계란용 새벽 준비 단계를 추가
- 계란 조리대 최대 Lv.3

손님 취향과 선호 메뉴 확률은 메뉴 해금 이후 단순 비율로만 처리한다. 손님 유형별 선호와 만족도는 후속 범위다.

## 9. 가판 외형 성장

외형은 별도 구매가 아니라 진행 마일스톤에 따라 바뀐다.

| 상태 | 조건 | 변화 |
|---|---|---|
| 시작 | 새 게임 | 낡은 천막, 좌석 1, 작은 간판 |
| 성장 | 점원 고용 + 좌석 2 | 넓어진 천막, 식기 더미, 종이등 1 |
| 완성 | Stage 01 완료 | 큰 간판, 종이등 2, 정돈된 조리대, 장식 깃발 |

## 10. 스테이지 완료 조건

다음을 모두 충족하면 Stage 01을 완료한다.

- Day 3 정산을 완료했다.
- 누적 60접시 이상 판매했다.
- 점원을 고용했다.
- 좌석 3개 이상을 해금했다.
- 계란 조리대를 해금했다.
- 계란 초밥을 누적 10접시 이상 판매했다.
- 고등어 조리대 Lv.4 이상을 달성했다.

목표 완료 예상 시간은 20~30분이다. 35분을 반복해서 넘기면 비용 또는 판매 속도를 낮춘다.

## 11. 완료 연출

- 영업 종료 후 가판이 완성 외형으로 바뀐다.
- `강가 가판대 완성` 결과 카드를 보여준다.
- 누적 판매량, 최고 일매출, 총 폐기량을 표시한다.
- 다음 장소의 실루엣만 보여주며 실제 Stage 02는 열지 않는다.
- `다시 운영하기`로 같은 스테이지를 계속 플레이할 수 있다.

## 12. 스테이지 수용 기준

- Day 1 핵심 시설은 초기 화면에 보이고, 확장 시설은 경계 안의 카메라 이동으로 모두 확인할 수 있다.
- 카메라는 단계 시작 시 관련 플레이 영역으로 초기화되고 맵 밖으로 이동하지 않는다.
- 첫 판매, 첫 업그레이드, 첫 좌석, 첫 직원의 목표 시점을 충족한다.
- Day 1에 시장이나 손질을 요구하지 않는다.
- Day 2에는 구매한 수량이 판매 가능량에 정확히 반영된다.
- 점원이 손님의 주문과 일치하는 메뉴만 전달한다.
- 계란 메뉴가 잠겨 있을 때 계란 주문이 발생하지 않는다.
- 스테이지 완료 조건이 UI 목표와 내부 판정에서 일치한다.
- 완료 후에도 저장 데이터가 유지되고 같은 스테이지를 재개할 수 있다.
